## What we're building

Axelrod is a self-verifying research harness for screening public companies. The analyst picks a company. The harness plans what evidence the BOFFIN framework needs and which sources to pull, and the analyst approves the priority sources. Agents then fetch, extract, draft and verify under one gateway, which enforces the approved sources, logs all traffic, blocks anything outside policy and stops on command. There are two outputs. The agent report: every data point is quoted exactly from a stored source and checked by code, every conclusion cites data, every BOFFIN score cites conclusions. The 3-page brief: every sentence cites the report. Every item and sentence carries a certainty score computed by code.

## Contract rules

1. `contract/models.py` is the source of truth. `contract/types.ts` is generated by `python contract/gen_types.py`. Never edit `types.ts` by hand.
2. To change a shape: edit `models.py`, regenerate `types.ts`, update the mock and fixtures in the same commit (`python mock/build_fixtures.py` must pass), add a line to `contract/CHANGELOG.md`, bump `contract/VERSION`, and tell the other person.
3. Adding things (a new optional field, a new event type) is safe. Renaming or removing needs both people.
4. The frontend ignores unknown event types, so the backend can add events without breaking the UI.
5. If the mock answers, the shape is right, because every mock response is validated against `models.py`.

## Running things

```
pip install -r mock/requirements.txt
uvicorn mock.mock_server:app --reload --port 8000   # mock API, from the repo root. Swagger: /docs
MOCK_SPEED=3 uvicorn mock.mock_server:app --port 8000   # replay 3x faster
python mock/build_fixtures.py                        # rebuild and re-validate the fixtures
python contract/gen_types.py                         # regenerate contract/types.ts
```

Frontend env: `NEXT_PUBLIC_API_BASE` (Next.js inlines it at build time, so restart `next dev` or rebuild after changing it). Unset means `http://localhost:8000/api/v1`, the mock. Real backend: the API Gateway invoke URL plus `/api/v1`.
